OPERATOR'S QUICK REFERENCE +

Click the screen before typing. On Mac, use Control for C- shortcuts and Option for M- shortcuts. Esc followed by x also opens the command prompt.

C-x C-f
Open or create a file in /work
C-x C-s
Save the current file
C-x C-e
Evaluate the expression before the cursor
C-g
Cancel the current command

To try application management, use the EVALUATE key and enter:

(progn (require 'emacsos-counter)
       (emacsos-counter-start)
       (emacsos-counter-start)
       (emacsos-processes))

In the application list: s stops a run, r restarts it, and RET shows details. Applications share one cooperative Emacs runtime.
