Browser runtime notices

The browser runs the current emacsOS image in a third-party QEMU/WebAssembly build, with xterm.js and xterm-pty providing its serial terminal. The asset manifest identifies the downloaded bytes and their source URLs. These files are cached locally, not committed to emacsOS.

Terminal

  • xterm.js 5.3.0: MIT notice; source.
  • xterm-pty 0.12.0: MIT notice; source.

Emulator and firmware

The QEMU/Wasm and BIOS package files come from this pinned artifact tree. QEMU contains code under multiple licenses, including GPL and LGPL; the demo repository's license does not replace those component licenses.

  • QEMU: COPYING, COPYING.LIB, and firmware notices and source references.
  • Emscripten: license notices.
  • GLib: LGPL notice.
  • libffi: license notice.
  • zlib: README and license notice.

The upstream QEMU/Wasm source and build instructions are a build reference. This integration pins prebuilt artifact hashes; it has not reconstructed the exact compiler, source revisions, linked libraries or firmware provenance of those artifacts. The notices above preserve upstream reference texts, without claiming an exact corresponding-source audit. Reconstructing that build and its complete distribution materials remains necessary before a public runtime distribution.

Guest system

The boot image is built separately from the emacsOS checkout and its pinned GNU Emacs fork. Its build manifest records component hashes and source identity. Guest Emacs license files accompany its runtime archive. This page does not change their licenses.
