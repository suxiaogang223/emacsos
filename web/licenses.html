Free software, all the way down.

emacsOS brings together GNU Emacs, Linux and a source-built QEMU/WebAssembly emulator. Parent-owned emacsOS code is licensed under GPL-3.0-or-later. Every third-party component keeps its original license.

Download the corresponding source

The browser release supplies binaries and source together:

  • Emulator and firmware sources: QEMU/Wasm, SeaBIOS, libfdt, key maps, linked libraries, Emscripten runtime, terminal sources, patches and build recipes.
  • Guest system sources: the exact GNU Emacs source and every installed Alpine package's source, build recipe, patches and configuration.
  • Parent source repository: Linux image policy, Emacs setup, browser presentation, scripts and tests.

Source archive hashes · Emulator asset hashes · Emulator build record · Guest build record · Guest package inventory

The emulator is built from QEMU/Wasm commit 0ef7b4e2814b231705d8371dd7997f5b72e70baf with Emscripten 3.1.50. SeaBIOS and the small Linux boot ROMs are compiled from the supplied sources. The serial-only browser profile has no VGA or network device and uses no precompiled firmware from the old demo bundle.
